# Pulse Docs

Documentation site for the Pulse trace service and SDK. Built with [Starlight](https://starlight.astro.build).

## Workspace commands

Run these from the monorepo root.

| Command             | Action                                      |
| :------------------ | :------------------------------------------ |
| `just setup`        | Install workspace dependencies              |
| `just docs-dev`     | Start the site at `localhost:4321`          |
| `just docs-check`   | Build the production site                   |
| `just docs-preview` | Preview the production build                |
