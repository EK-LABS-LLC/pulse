## Sessions

A session groups related traces together, such as a user conversation, agent run, or batch job.

Pulse uses this hierarchy:

```text
Pulse session
  OTel trace = one LLM call, agent turn, task, or workflow
    OTel span = one timed operation inside that trace
```

Assign a session ID and all traces with that ID appear together in the dashboard.

## Setting a session ID

### At observe-time

Pass `sessionId` in observe options. All calls through this client use this session.

<Tabs>
  <TabItem label="TypeScript">

```ts
const client = observe(
  new OpenAI({ apiKey: "sk-..." }),
  Provider.OpenAI,
  {
    sessionId: "conv-abc-123",
    sessionName: "Support refund conversation",
    traceName: "Answer refund policy question"
  }
);
```

  </TabItem>
  <TabItem label="Python">

```python
client = observe(
  OpenAI(api_key="sk-..."),
  Provider.OPENAI,
  {
    "session_id": "conv-abc-123",
    "session_name": "Support refund conversation",
    "trace_name": "Answer refund policy question",
  }
)
```

  </TabItem>
</Tabs>

### Per-call override

Pass `pulseSessionId` in the request body to override the observe-time session for one call.

<Tabs>
  <TabItem label="TypeScript">

```ts
await client.chat.completions.create({
  model: "gpt-4o",
  messages: [{ role: "user", content: "Hello" }],
  pulseSessionId: "different-session-456",
  pulseSessionName: "Escalated support conversation",
  pulseTraceName: "Draft escalation response",
});
```

  </TabItem>
  <TabItem label="Python">

```python
client.chat.completions.create(
  model="gpt-4o",
  messages=[{"role": "user", "content": "Hello"}],
  pulse_session_id="different-session-456",
  pulse_session_name="Escalated support conversation",
  pulse_trace_name="Draft escalation response",
)
```

  </TabItem>
</Tabs>

Per-call values take precedence. `pulseSessionId` is stripped before the request reaches the provider.

## Metadata

Attach arbitrary key-value data to traces for filtering by user, feature, environment, or any custom dimension.

### At observe-time

<Tabs>
  <TabItem label="TypeScript">

```ts
const client = observe(
  new OpenAI({ apiKey: "sk-..." }),
  Provider.OpenAI,
  {
    metadata: {
      userId: "user-123",
      environment: "production",
    },
  }
);
```

  </TabItem>
  <TabItem label="Python">

```python
client = observe(
  OpenAI(api_key="sk-..."),
  Provider.OPENAI,
  {
    "metadata": {
      "user_id": "user-123",
      "environment": "production",
    }
  }
)
```

  </TabItem>
</Tabs>

### Per-call extension

Pass `pulseMetadata` in request body. It merges with observe-time metadata and per-call values win on conflicts.

<Tabs>
  <TabItem label="TypeScript">

```ts
await client.chat.completions.create({
  model: "gpt-4o",
  messages: [{ role: "user", content: "Summarize this" }],
  pulseMetadata: {
    feature: "summarizer",
    version: "2.1",
  },
});
```

  </TabItem>
  <TabItem label="Python">

```python
client.chat.completions.create(
  model="gpt-4o",
  messages=[{"role": "user", "content": "Summarize this"}],
  pulse_metadata={
    "feature": "summarizer",
    "version": "2.1",
  },
)
```

  </TabItem>
</Tabs>

## ObserveOptions

The third argument to `observe()`:

| Field | Type | Description |
| --- | --- | --- |
| `sessionId` | `string` | Default session ID for all calls through the client. |
| `sessionName` | `string` | Human-readable name for the dashboard session. |
| `traceName` | `string` | Human-readable name for traces created by this client. |
| `promptPreview` | `string` | Optional prompt preview used as a display fallback. |
| `metadata` | `Record<string, unknown>` | Metadata merged into every trace from this client. |

## Per-call params

These request fields are stripped before sending to the provider:

| Field | Type | Description |
| --- | --- | --- |
| `pulseSessionId` | `string` | Override session ID for this call only. |
| `pulseSessionName` | `string` | Override session display name for this call. |
| `pulseTraceName` | `string` | Override trace display name for this call. |
| `pulsePromptPreview` | `string` | Override prompt preview for this call. |
| `pulseMetadata` | `Record<string, unknown>` | Merge additional metadata for this call. |

## Viewing sessions

In the dashboard, navigate to **Sessions** to see sessions, click a session to see trace summaries, then click a trace to inspect its spans.

Via API:

```bash
GET /v1/sessions/:id
```

Returns all traces for the session. See [REST API](/docs/api/).
